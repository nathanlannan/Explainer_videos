# Episode 1 glossary — Measure Once: The Story Stick

Only this episode's terms. Kanji are shown because each term is verified in two independent sources (see `research/research_table.md`). Pronunciation: see `shared/audio/voice/pronunciation.md`.

| Romaji | Kanji | Kana | English gloss | One-line description |
|---|---|---|---|---|
| sumitsuke | 墨付け | すみつけ | layout marking | Drawing every line and mark on the timber in ink, before any cutting (R-01). |
| shinzumi | 芯墨 (also written 心墨, 真墨) | しんずみ | center line ink | The ink line down the middle of a member; Japanese layout is measured from it (R-02, R-03). |
| bakabō | 馬鹿棒 | ばかぼう | story stick (shop nickname); literally "fool's stick" | A plain stick carrying every position, copied to each piece. The usual explanation of the name: with it, anyone gets the same length every time. That explanation is folk etymology, so treat it as "usual", not proven (R-08, R-09). |
| ita-zu | 板図 | いたず | board plan | A carpenter's simple plan of the whole building drawn on a board, with each piece named; used while marking out (R-11). Covered in Episode 3. |

Related terms (not used on screen in Ep 1; for later): 尺杖 shakuzue and 間竿 kenzao (graduated carpenter's rods); 矩計杖 kanabakari-zue / 竪杖 tatezue (a rod carrying post heights) (R-10).
